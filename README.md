# AI Assistant для Evolution CMS

AI-ассистент в менеджере Evolution CMS. Управляйте содержимым сайта через чат:
находите и редактируйте страницы, создавайте разделы, шаблоны и TV, проверяйте SEO
и откатывайте изменения.

## Возможности

- Поиск, создание, редактирование, публикация и снятие страниц с публикации.
- Создание и редактирование шаблонов, включая Blade.
- Создание TV, привязка к шаблонам и заполнение значений на страницах.
- SEO-анализ страниц и предложения по оптимизации.
- Контрольные точки и откат изменений страниц, TV и шаблонов.
- Каталог моделей OpenRouter с поддержкой инструментов и ценами.

## Требования

- **Evolution CE 3.1.31** — проверенная версия CMS.
- **PHP 8.1–8.4**, расширения JSON и mbstring, Composer 2.
- Рабочая установка CMS с её зависимостями и базой данных.
- API-ключ выбранного провайдера и модель с поддержкой вызова инструментов (`tools`).
- Учётная запись администратора CMS: **роль 1**.

## Установка

Сначала сохраните резервную копию файлов сайта и базы данных.
Затем выполните из корня сайта:

```sh
mkdir -p core/custom/packages
git clone https://github.com/zif91/evo_ai_assistant.git core/custom/packages/ai-assistant
php core/custom/packages/ai-assistant/install.php
cd core
composer dump-autoload
php artisan package:discover
php artisan cache:clear-full
```

Установщик создаст таблицы, зарегистрирует пакет, добавит плагин и модуль настроек,
скопирует CSS и JS. Существующие настройки сохраняются.

## Настройка

1. В менеджере откройте **Модули → AI Assistant Settings**.
2. Выберите протокол, укажите API Base URL, API Key и Model ID.
3. Нажмите **«Сохранить»** и перезагрузите менеджер.

| Подключение | Протокол в настройках | API Base URL | Model ID |
| --- | --- | --- | --- |
| OpenRouter | OpenRouter / OpenAI-compatible | `https://openrouter.ai/api/v1` | Выберите из каталога |
| OpenAI | OpenRouter / OpenAI-compatible | `https://api.openai.com/v1` | ID OpenAI без префикса `openai/` |
| Anthropic | Anthropic (прямой API) | `https://api.anthropic.com/v1` | ID Anthropic без префикса `anthropic/` |
| Совместимый API | OpenRouter / OpenAI-compatible | HTTPS-адрес вашего API | ID поддерживаемой модели |

Выбор модели из каталога автоматически переключает подключение на OpenRouter.
Можно ввести Model ID вручную. Каталог обновляется раз в сутки или кнопкой
**«Обновить каталог»**; при недоступности API показывается сохранённый список.
Пустое поле API Key при сохранении оставляет прежний ключ. Для Anthropic пакет
использует фиксированный адрес Messages API.

По умолчанию выбрана платная модель `openai/gpt-5.4-mini`. Для бесплатного теста
выберите в каталоге модель с суффиксом `:free` и ценами **$0 / $0**.
У бесплатных моделей тоже есть ограничения доступности и числа запросов.

## Использование

Откройте ассистента фиолетовой кнопкой справа или сочетанием **Ctrl/Cmd + Shift + A**.
Примеры запросов:

- «Найди страницы, где упоминается доставка».
- «Создай раздел Каталог с двумя дочерними страницами».
- «Создай TV price и привяжи её к шаблону Продукт».
- «Проанализируй SEO страницы #12».

Изменения применяются сразу. Новые страницы по умолчанию не опубликованы.
Если задача завершилась с ошибкой, уже выполненные действия могут сохраниться —
проверяйте их результаты в чате.

Кнопка **«Точки восстановления»** открывает доступные откаты. Они возвращают
изменённые поля и Blade-файлы. Создание страниц, шаблонов и TV, а также привязки TV
автоматически не откатываются. История чата хранится в сессии менеджера.

## Обновление

Сделайте резервную копию, обновите файлы пакета и повторите команды установки,
начиная с `php core/custom/packages/ai-assistant/install.php`.
Повторный запуск сохраняет настройки и не дублирует плагин и модуль.

При переходе со старой версии удалите вручную добавленную группу AI Assistant
из `core/custom/routes.php`, если она там есть: пакет регистрирует маршруты сам.

## Если что-то не работает

- **Панель или API возвращает 404:** маршруты `/ai-assistant/*` должны попадать
  в корневой `index.php` CMS. Проверьте правила сервера или своего роутера для `php -S`.
- **Нет доступа:** войдите в менеджер администратором с ролью 1.
  При ошибке CSRF перезагрузите панель или страницу настроек.
- **Ошибка AI:** проверьте ключ, URL, ID модели, поддержку `tools` и лимиты провайдера.
- **Ошибка JSON или PHP-предупреждения в ответе:** отключите `display_errors`
  на веб-сервере и проверьте журнал PHP. Ядро Evolution 3.1.31 может выдавать
  предупреждение об устаревшем `E_STRICT` на PHP 8.4.

## Разработка и проверки

```sh
composer install
git clone --depth 1 --branch 3.1.31 https://github.com/evocms-community/evolution.git /tmp/evolution
EVO_SOURCE=/tmp/evolution composer test
```

[CI](https://github.com/zif91/evo_ai_assistant/actions/workflows/compatibility.yml)
проверяет PHP 8.1–8.4. [Протокол установки на действующую CMS](docs/installation-verification.md)
содержит результаты проверки менеджера, MySQL, бесплатной модели и отката.
