# Changelog

## 1.1.0 — 2026-10-09

- Живой каталог OpenRouter с tool calling, ценами, кешем, резервным снимком и ручным ID.
- Единый CLI-установщик: корректные пути, схема БД, provider discovery, обновление
  модуля и плагина без потери ключей и перезаписи чужих конфигураций.
- Совместимость с исходниками Evolution CE 3.1.31 / Illuminate 8; матрица PHP 8.1–8.4.
- Доступ администратора, CSRF, безопасный вывод ответов и результатов инструментов,
  проверка источника postMessage и ограничение путей Blade.
- Claude tool_use/tool_result, сохранение reasoning metadata OpenRouter,
  max_completion_tokens прямого OpenAI, проверка JSON и ошибок HTTP 200.
- Честный результат при лимите шагов и частичном выполнении, ограниченная история,
  инициализация сервисов для всех API endpoint, применение флагов actions.
- Исправления TV templates, отката Blade, порядка отката, очистки кеша,
  русскоязычного SEO-подсчёта и положения закрытой панели.
- Интеграционные проверки и GitHub Actions.
