# Проверка установки — 2026-10-09

Среда: существующая локальная Evolution CE 3.1.31, PHP 8.4.1, MySQL 9.0.1.
Перед изменениями сохранены полный архив сайта и SQL-дамп; проверены SHA-256.
Рабочий сайт и исходная БД сохранены. Боевой сервер не использовался.

## Установка

Репозиторий размещён в `core/custom/packages/ai-assistant`. Выполнены ровно команды
из README: `install.php`, `composer dump-autoload`, `package:discover`,
`cache:clear-full`. Все завершились с кодом 0. Повторная установка не создала
дубликатов плагина и модуля и сохранила настройки.

Локальный сайт использует собственный dev-router. В нём добавлена передача
`/ai-assistant/*` корневому `index.php`. Для HTTP отключён `display_errors`,
чтобы предупреждение ядра Evolution об E_STRICT не добавляло HTML к JSON.

## Проверки через менеджер и HTTP

- Настоящий вход через форму менеджера; анонимный API получает 401,
  изменение без CSRF — 403.
- Переход «Модули → AI Assistant Settings», загрузка живого каталога,
  сохранение настроек с пустым полем ключа: прежний ключ сохранён и не выведен в HTML.
- Панель, CSS и JS загружаются без ошибки; история восстанавливается после перезагрузки.
- Через HTTP созданы отдельные тестовые шаблон, страница и TV, проверена привязка
  и сохранение TV. Текст страницы изменён и возвращён через контрольную точку.
- Через интерфейс чата модель `nvidia/nemotron-3-super-120b-a12b:free`
  ответила на проверочное сообщение, создала неопубликованную тестовую страницу
  и изменила её текст инструментами. В каталоге вход и выход модели стоят $0.
  Платные модели и fallback на них не использовались.
- Откат из интерфейса панели вернул исходный текст: результат проверен отдельным
  чтением MySQL через HTTP API. Новый объект и редакция записывают ID администратора.

## Исправления, найденные реальной установкой

1. В Evolution `url()` принимает ID документа. Пути CSS/JS панели теперь строятся
   от `MODX_SITE_URL`, включая установки в подпапке.
2. API входит через frontend: права и ID пользователя нужно получать в `mgr`.
   На время авторизованного обработчика middleware также переключает контекст
   в `mgr`, чтобы события моделей Evolution записывали правильного автора;
   исходный контекст восстанавливается в `finally`.
3. Форма менеджерского модуля требует штатный `_token` Evolution в дополнение
   к `_ai_token` ассистента. Без него ядро отклоняло сохранение до выполнения модуля.

Добавлены регрессионные проверки. Основной набор: 37 проверок с реальными моделями
и схемами Evolution 3.1.31; матрица CI — PHP 8.1–8.4.

## Границы проверки

Проверена указанная локальная установка. Прямые API OpenAI и Anthropic покрыты
имитацией HTTP, но в этой приёмке не вызывались. Evolution 1.4, другие форки и PHP
8.5 не проверены. Доступность бесплатной модели зависит от лимитов OpenRouter.

## Завершение проверки

Тестовые страницы, шаблоны, TV, контрольные точки и временный администратор
удалены. Временно использованный API-ключ убран. На локальном сайте оставлена
бесплатная модель; для дальнейшей работы нужно указать свой ключ.
После очистки строки исходных страниц, шаблонов, TV, значений и привязок TV,
а также пользователей и их атрибутов побайтно совпали с INSERT-записями
SQL-дампа до установки. Сохранены исходные 66 страниц, 13 шаблонов, 36 TV,
821 значение TV и 170 привязок. Изменения установщика и запись служебных
журналов менеджера остаются ожидаемым результатом установки и проверки.
